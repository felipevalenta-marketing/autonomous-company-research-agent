Technical Challenge

The Most Important Technical Challenge

Microsoft retrieval failed even though the providers returned HTTP 200. Stored metadata read MICROSOFT CORP, while the resolved identity was Microsoft Corporation — so the strict normalization layer rejected valid Pinecone matches.

Before

MICROSOFT CORP

≠

Microsoft Corporation

After

microsoft

=

microsoft

Solution: alias-aware, legal-suffix normalization — while preserving strict rejection of genuinely different companies.

  • Microsoft retrieval restored
  • Regression tests added
  • Full suite of 550 tests remained green

Biggest Mistake

My Biggest Mistake

I validated individual components before validating the complete production path. OpenAI returned HTTP 200. Pinecone returned HTTP 200. The workflow completed — but the final evidence bundle was empty, because local metadata and normalization contracts were inconsistent.
