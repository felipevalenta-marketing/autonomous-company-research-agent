Technical Challenge

The hardest part was not calling an API

The real difficulty was keeping a contract-driven pipeline consistent across SEC documents, chunking, embeddings, vector metadata, Pinecone, and LangGraph state.

A chunk's text_id had to survive vector preparation exactly. A string-normalization step was silently modifying it, which broke the downstream vector-preparation contract. The fix preserved text_id verbatim while keeping every other metadata validation rule intact.

Focused regression tests were added and the complete suite remained green.

Biggest Mistake

I built too much before validating the full live path

The architecture and individual services became highly detailed and heavily tested — but live provider credentials, infrastructure, and full end-to-end execution should have been validated earlier. That surfaced environment and integration issues later than it should have.

Before
  1. Design every layer
  2. Build every service
  3. Test everything
  4. Connect live providers later
Better approach
  1. Connect one real provider
  2. Validate one complete vertical slice
  3. Expand safely
  4. Automate
Architecture matters, but the first working vertical slice matters more.
